CRYPTO COPILOT 2.2.4

This repository is the Chrome/Brave extension.

INSTALL:
1. Download ZIP from GitHub.
2. Extract the ZIP.
3. Open chrome://extensions/ or brave://extensions/
4. Enable Developer mode.
5. Click Load unpacked.
6. Select the crypto-copilot-main folder.

IMPORTANT: The folder selected in Load unpacked MUST contain manifest.json directly.
Do not select a subfolder.

The extension manifest is in the repository root.
